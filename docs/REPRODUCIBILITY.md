# 复现范围与验收

示例计算完成于 2026-10-23，受约束序列库于 2026-10-24 使用六条 Debian 设计重新评分。作者使用 Debian 13.7、RTX 3060 12GB、驱动 550.163.01。读者使用其他 Linux 环境时，应保存自己的软件版本、模型权重、种子和命令。

`practice.py analyze` 复算已保存的输入或模型输出；`practice.py run` 预览新的计算，附加 `--execute` 才启动外部工具。前者的通过不能写成重新完成了 GPU 推理，后者的退出码为零也不代表候选满足科学筛选。执行器核对预期文件，章节分析再核对数值、序列身份与几何。

ProteinMPNN 与序列评分保存掩码和随机顺序，因此可复算 NLL；重新推理仍可能受到 PyTorch、CUDA 和硬件差异影响。RDKit 构象数量也可能随版本变化，应先检查化学身份、收敛与采样设置，再比较具体数值。不要为匹配教材小数而修改数据。

MD 的 Factor Xa 与多肽 MDM2/p53 是独立体系；Boltz 小分子亲和力案例与 p53 结构任务也是独立输入。HADDOCK 的小鼠输入使用人源同源参考评价，存在物种与映射限制。不同模型在一个小体系上的差异不构成普遍准确率排名。

AF3 本轮没有可靠恢复参考摆放；BoltzGen 两条候选零条通过全部筛选；RFdiffusion2 下游配体几何保持不足。这些负结果保留在分发包中。ESMFold2 保持未执行，不能用其他预测阶段的结果替代。

基础仓库经过逐章分析和可搬迁目录检查，具体验证记录见 `provenance/validation.json`。新移植的 GPU 执行入口提供命令计划与产物检查；它们来自原 Debian 已运行阶段，本次打包没有重新执行全部昂贵 GPU 计算。读者应先预览、检查版本和资源，再运行小规模任务。
