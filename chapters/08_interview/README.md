## 怎样自测

十二个核心题各 0–3 分，满分 36；建议达到 30 且无 0 分，再扩大工具覆盖。

## 独立练习与交付

合上答案，用五分钟讲述一条主线，再随机抽一行 CSV 解释其来源、单位与下一步。只把亲自完成的操作描述为自己的贡献。

保存实际输入、版本、命令、结果和一段解释。新计算的 `execution.json` 核验退出码与产物，候选是否达到研究目标还要继续读分数、几何和过滤标志。
